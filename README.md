# 📚 The Complete CS Core Subjects Preparation

A collection of **Computer Science study material, notes, important questions, and exam/interview preparation resources** covering the core subjects of Computer Science.

This repository is useful for **B.Tech / BCA / MCA students, placements, exams, and CS interview preparation**.

## 📖 Subjects Covered

### 🗄️ DBMS — Database Management System
- DBMS fundamentals
- ER Model
- Relational Model
- SQL
- Keys and Constraints
- Normalization
- Transactions
- ACID Properties
- Concurrency Control
- Indexing
- Joins
- Subqueries
- Important exam questions

### 💻 Operating System
- OS fundamentals
- Processes and Threads
- CPU Scheduling
- Process Synchronization
- Deadlocks
- Memory Management
- Paging and Segmentation
- Virtual Memory
- File Systems
- Disk Scheduling
- Important exam and interview questions

### 🌐 Computer Networks
- Network fundamentals
- OSI Model
- TCP/IP Model
- Network Topologies
- IP Addressing
- Subnetting
- TCP and UDP
- HTTP and HTTPS
- DNS
- Routing
- Network Security
- Important exam and interview questions
